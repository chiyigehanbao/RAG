# NovaCloud 前端 UI 改版 — 设计规格

> 状态：已批准（2026-05-24）  
> 前置：Phase 1 MVP 功能完整  
> 目标：产品官网助手气质，作品集可截图交付

---

## 1. 背景

Phase 1 前端为 Tailwind 默认蓝灰 SaaS 样式，功能完整但视觉偏「快速 Demo」。用户要求优先 UI，方向为**产品官网内的知识库助手**，Phase 2（grade/rewrite/上传）延后。

---

## 2. 选定方向：云端客服台

- 浅色、柔和景深、圆角浮卡
- 调试能力包装为侧栏 **「Agent 洞察」**，非工程师 IDE 面板
- 主色：深海蓝 `#0B3D5C` + 天青强调 `#2DD4BF`
- 字体：Outfit（标题）+ DM Sans（正文）+ JetBrains Mono（调试）

---

## 3. 页面与组件

### 3.1 全局（App）

- 顶栏：Logo +「知识库助手」+ 导航（对话 / 文档）
- 背景：暖灰 + 径向光晕（CSS）
- 页脚：技术栈一行小字

### 3.2 对话页

- 空状态 Hero + 分类示例卡片
- 用户/助手气泡样式区分，助手带头像
- 输入区圆角大框 + 加载文案
- 侧栏「Agent 洞察」（宽屏右、窄屏下）

### 3.3 调试侧栏

- 竖向步骤时间线
- 检索卡片 + distance 可视化
- 引用列表、JSON 默认折叠

### 3.4 文档管理页

- 统一顶栏/背景
- 表格 pill 状态、强调色描边「重新索引」
- 共用 EmptyState

---

## 4. 不动项

- `api/client.ts`、`api/types.ts`、后端 API
- Agent 逻辑与 trace 数据结构
- Phase 2 rewrite 历史（仅保留侧栏结构可扩展）
